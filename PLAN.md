# План: кнопки «О чем статья», «Тезисы», «Пост для Telegram»

Основание: [PROJECT.md](./PROJECT.md)

## Цель

Подключить AI (OpenRouter) к трём кнопкам: краткое описание статьи, тезисы и пост для Telegram. В конце поста для Telegram всегда добавлять ссылку на источник.

## Порядок действий

### Этап 1. Общий AI-клиент
1. Вынести в `lib/openrouter.ts` общую функцию `chatCompletion` (ключ, модель, обрезка текста).
2. Сохранить существующий `translateArticle`.
3. Добавить три функции генерации:
   - `summarizeArticle` — краткое описание (2–4 предложения на русском);
   - `generateTheses` — 5–10 тезисов;
   - `generateTelegramPost` — короткий пост для Telegram; в конце дописывать URL источника.

### Этап 2. API-маршруты
4. Создать `POST /api/summary` — парсинг URL → AI-описание → `{ text }`.
5. Создать `POST /api/theses` — парсинг URL → AI-тезисы → `{ text }` (или `{ items }`).
6. Создать `POST /api/telegram` — парсинг URL → AI-пост + ссылка на источник → `{ text }`.
7. Оставить `/api/parse` и `/api/translate` без поломки.

### Этап 3. Интерфейс
8. В `app/page.tsx` направить кнопки на новые API:
   - «О чём статья?» → `/api/summary`
   - «Тезисы» → `/api/theses`
   - «Пост для Telegram» → `/api/telegram`
9. Показывать результат вертикально: заголовок (если есть) и текст ответа.
10. Добавить понятные статусы загрузки для каждой кнопки.

### Этап 4. Проверка и деплой
11. Локальная сборка `npm run build`.
12. Зафиксировать изменения и задеплоить на Vercel.
13. Записать ссылку на Vercel в `REPORT.md`.
