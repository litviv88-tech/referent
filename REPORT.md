## Что сделано

### Дружественные ошибки
- Типы ошибок: `INVALID_URL`, `ARTICLE_FETCH_FAILED`, `ARTICLE_EMPTY`, `AI_NOT_CONFIGURED`, `AI_FAILED`, `UNKNOWN`.
- API больше не отдаёт сырые тексты OpenRouter/fetch.
- Если статью нельзя загрузить (404, 500, таймаут и т.п.): **«Не удалось загрузить статью по этой ссылке.»**
- Ошибки показываются через shadcn-подобный **Alert**.

### Кнопки и результат
- **«Очистить»** — сброс URL, результата, ошибок и состояний.
- **«Копировать»** в блоке «Результат».
- После успешной генерации страница автоматически прокручивается к результату.

### Адаптив
- Мобильный (~375–430px): кнопки столбиком, `px-4`, текст с `break-words`.
- Планшет (~768px) и десктоп: кнопки в строку (`md:flex-row`).

### Улучшение по выбору
Добавлен запуск **«О чём статья?»** по клавише **Enter** в поле URL и визуальный отклик **«Скопировано»** после копирования.
